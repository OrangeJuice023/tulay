# Research workspace

Findings that shape Tulay's product and data decisions. Protocol and report template:
`docs/RESEARCH_PROTOCOL.md`. Default owner: Kilo.

| Path | Question it answers | Status (2026-10-28) |
| --- | --- | --- |
| `market/philippines.md` | How big and how underserved is the PH freelancer / career-shifter group? | Questions only |
| `competitors/competitor-landscape.md` | What do people use today, and where does Tulay differ? | Questions + candidate list (unverified) |
| `data-sources/source-registry.md` | Which job-data sources can we legally use, and how? | Registry format + leads (unverified) |
| `user-needs/validation-plan.md` | Do target users actually want consent-based reciprocal help? | Plan drafted |
| `findings/` | Short dated notes and finished reports that don't fit above | Empty index |

International market and job sources are tracked inside the same files under an "International"
heading until there is enough to justify separate files.

Not here: raw data (`data/raw/`), transformed data (`data/processed/`), synthetic demo data
(`data/fixtures/`).

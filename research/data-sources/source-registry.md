# Data source registry

Every external data source considered for Tulay, especially job listings. A source may only be
imported once its row is **Approved** with licence and API facts verified from official pages.

Job listings are not in the MVP. This registry exists so that the later decision is evidence-based.

## Fields

| Field | Meaning |
| --- | --- |
| Name / URL | Official site |
| Country | ISO code(s) covered |
| Access | Official API / bulk download / none. "API" only if official docs exist; link them. |
| Licence and terms | Link to terms; whether storage, reuse and display are allowed |
| Auth / cost | Key required, pricing |
| Update frequency | |
| Relevant fields | For example title, skills, location, pay, currency |
| Verified on | YYYY-MM-DD and by whom |
| Status | Lead / Under review / Approved / Rejected (with reason) |
